# Vishwanth Jakka — Portfolio

Personal portfolio site (Vite + React client, Express API).

## Run locally

```bash
npm install
npm run dev
```

Open [http://127.0.0.1:5005](http://127.0.0.1:5005).

Contact form submissions are stored in memory for local development (no database required).

## Scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Dev server (API + Vite) on port 5005 |
| `npm run build` | Production client build |
| `npm run check` | TypeScript check |
